Breaking changes:

- The key used to override LSP-SonarLint settings in project settings has changed from `SonarLint` to `LSP-SonarLint`.
  If you use project-specific overrides for LSP-SonarLint, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "SonarLint": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-SonarLint": {
                  // ...
              }
          }
      }
  }
  ```
